# 🦖 DinoRunnerUnity

**DinoRunnerUnity** é um jogo de corrida infinita (endless runner) desenvolvido na **Unity**, totalmente inspirado no clássico minijogo do dinossauro do Google Chrome.

### 🚀 Tecnologias Utilizadas
* **Unity** — Engine de desenvolvimento do jogo.
* **C#** — Linguagem de programação para a lógica e mecânicas.

### 🎮 Como Jogar
1. Clone o repositório ou baixe o projeto.
2. Abra a cena principal na Unity.
3. Pressione a **Barra de Espaço** para pular os obstáculos e tentar alcançar a maior pontuação possível!
